# Store and privacy material

This is an owner-input template for Phase 6. It is not a store submission and does not claim approval.

## Product facts currently supported by the implementation

Product working name: Draw Duo. Final name and trademark clearance: OWNER INPUT REQUIRED.

Supported launch targets: Windows desktop test packaging and Android test packaging. Steam and Google Play publication: OWNER APPROVAL REQUIRED.

Game description: two players cooperate online, taking turns drawing and guessing from private word choices. They share a team score and duo streak, while each player receives equal earned coins from solved turns.

Online requirement: an internet connection and compatible backend are required for live rooms, matchmaking, friend-code joins, account recovery, and progression synchronization.

Cross-play statement: Windows and Android use the same React client behavior, Colyseus room protocol, account namespace, ruleset, and player population. Packaged cross-platform gameplay is still a required release gate and is not claimed here.

Supported inputs: mouse and touch drawing, physical keyboard tile selection where available, and on-screen letter tiles. Steam Deck, controller, iOS, and accessibility certification are not claimed.

Monetization: the current build has no ads, rewarded ads, real-money purchases, paid gameplay advantages, or watch-an-ad rewards. Gameplay-earned coins are separate from any future commercial entitlement.
